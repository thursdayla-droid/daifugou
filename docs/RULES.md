# ルールと 仕様（2026-11-22〜）

## 依頼どおりのルール（確定）

| カード | 名前 | 発動 | 内容 |
|---|---|---|---|
| 3 | ドロースリー | 任意 | 墓地からランダムで3枚見て、好きな1枚を手札に加えられる |
| 4 | トレードフォー | 強制 | 次の人と手札を伏せ、お互いに1枚選んで交換 |
| 5 | ゴ飛び | 強制 | 次の人をスキップ |
| 6 | エクゾディア | ― | 手札に6が4枚そろったら そのゲームの勝者 |
| 7 | ナナ渡し | 強制 | いらないカードを次の人に渡す |
| 8 | ヤ切り | 強制 | 出した瞬間に場が流れる |
| 9 | リビングデッドのエクナイン | 任意 | 出したマークと同じ6を、墓地か持っている人の手札から回収 |
| 10 | ジュ捨て | 強制 | 好きなカードを墓地に捨てる |
| J | イレブンバック | 強制 | 数字の強さが逆になり3が一番強い（**ゲームの最後まで**。2026-11-22 決定） |
| Q | クイーンリバース | 強制 | 回る向きが逆になる |
| K | キングチャレンジ | 強制 | 墓地をシャッフルし一番上のマークを当てたら手札を2枚捨てられる |
| A | エースカウンター | 任意 | ナナ渡しを受ける時、エースを捨てて逆に相手へ1枚渡せる |
| 2 | ― | ― | なし |
| JOKER | ― | ― | 一番強い。2枚以上で出す時はほかの数字の代わりになれる（9以外）。エクゾディア・エースカウンターには使えない |

- 8切り・ジョーカーでの上がり禁止
- マークしばりあり（片しばりなし）
- 階段あり
- 革命あり（同じ数字4枚、マークのそろった階段4枚）
- ダイヤの3を持っている人から始まる
- スペードの3はジョーカーより強い
- 色：ゴールド。♠♣ 黒、♥♦ 赤
- オンライン対戦：部屋番号（4けた）で集まる。2〜6人、足りない分はCPU（2026-11-22 決定）

## 2026-11-22 友だちの答えで決まったこと
- ジョーカーは **1枚**
- 5・7・10 は 出した枚数ぶん（5を2枚→2人とばす 等）。3・4・9・K・J・Q は 何枚出しても1回
- **階段にも効果あり**。中のカードの効果が 弱い順に 1枚ずつ出る（例：♠7・8・9 → 1枚渡す → 場が流れる → ♠6を回収）。階段に8が入っていると その階段では上がれない
- エースカウンターを使うと ナナ渡しはなくなり、代わりに受ける側が1枚渡す
- 配った時点で 6が4枚そろっていたら その場で勝ち
- 大富豪と大貧民の カード交換は 試作のあいだは なし
- 一度パスしても、場が流れる前にまた回ってきたら出せる
- 8・ジョーカーでしか上がれず、親番で出せるカードが1つもない時は 反則負け（最下位）

## 仮で決めたこと（まだ確認していない）
1. 階段に ジョーカーは 使えない
2. ジョーカーを ほかの数字の代わりにした時は、その数字の効果も出る（例：5＋JOKER＝ゴ飛び2人）
3. ジョーカー1枚だけで出した時は 効果なし
4. しばり：前の人と全く同じマークの組み合わせで出すと しばり。ジョーカー入りの時は しばりにならない。しばり中ジョーカーは どのマークの代わりにもなれる
5. スペードの3がジョーカーに勝つのは、ジョーカー1枚に スペードの3を1枚 出した時だけ
6. ドロースリー：墓地が3枚より少ない時は あるだけ見る。墓地が0枚なら何もなし
7. トレードフォー：先に出した人が相手の伏せた手札から1枚選び、次に相手が選ぶ。並びは毎回まぜる
8. エクナイン：回収できる6が 自分の手札・場に あるときは なし
9. キングチャレンジ：墓地が0枚・手札が0枚なら なし
10. エクゾディアの時、残りの順位は 先に上がった人 → 手札の少ない順
11. ゲーム中に通信が切れた人は CPU が代わりに打つ
12. 時間制限は なし
