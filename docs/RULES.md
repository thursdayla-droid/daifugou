## 2026-11-22 友だちの答えで決まったこと
- ジョーカーは **1枚**
- 5・7・10 は 出した枚数ぶん（5を2枚→2人とばす 等）。3・4・9・K・J・Q は 何枚出しても1回
- ~~階段にも効果あり~~（同じ日に 変更：階段は4枚だけ・効果なし）。中のカードの効果が 弱い順に 1枚ずつ出る（例：♠7・8・9 → 1枚渡す → 場が流れる → ♠6を回収）。階段に8が入っていると その階段では上がれない
- エースカウンターを使うと 7渡しはなくなり、代わりに受ける側が1枚渡す
- 配った時点で 6が4枚そろっていたら その場で勝ち
- 大富豪と大貧民の カード交換は 試作のあいだは なし
- 一度パスしても、場が流れる前にまた回ってきたら出せる
- 8・ジョーカーでしか上がれず、親番で出せるカードが1つもない時は 反則負け（最下位）

- イレブンバックは 場が流れたら終わり（前の「ゲームの最後まで」から変更）
- ドロー3は 先に使うか選び、使うなら 必ず1枚 取る
- 名前：ドロー3・トレード4・5飛び・ケメゾディア・7渡し・8切り・リビングデッドのケメナイン・10捨て

- 2枚出しの時（2026-11-22 決定）
  - Q：リバースのリバースで 向きは そのまま（3枚なら逆）
  - 5：2人とばして 自分から数えて4番目の人の番
  - 9：2つのマークの6を 回収できる。1枚だけでもよい
  - K：2回 チャレンジ

- エースカウンターの枚数（2026-11-22 依頼者）：7を2枚出されたら エース2枚で 2枚カウンター（2枚捨てて 2枚返す）。エースが1枚なら 1枚だけカウンターして、残りの1枚は 7を出した人から 受け取る。何枚使うかは 受ける人が選ぶ

- 階段は 革命の4枚だけ出せる。そのとき 役の効果（8切り・7渡し 等）は 出ない（2026-11-22 依頼者）
  - 【仮】5枚以上の階段は 出せない
  - 【仮】効果がないので、階段の中の8・ジョーカーなしなら その階段で 上がってもよい

- ドロー3の枚数（2026-11-22 依頼者）：3を2枚なら 墓地から6枚見て2枚、3枚なら 9枚見て3枚 取る（使うなら 必ずその枚数）

- トレード4の枚数（2026-11-22 依頼者）：4を2枚なら 2枚ずつ、3枚なら 3枚ずつ 交換（手札が足りない時は ある分だけ）
- 効果の発動演出（2026-11-22 依頼者「遊戯王みたいな 役にあったエフェクト」）：出したカードが 光って落ちてきて、役ごとの色と記号（8切り＝赤い斬撃、10捨て＝炎、Qリバース＝回る矢印 など）と 名前が出る。約1.3秒（11-22 に 軽く・小さめ、11-23 に 少し長く）。絵や ロゴは 既存作品のものを 使わない（src/activate.ts）

- 革命を出した時（同じ数字4枚・ジョーカー入りも・階段4枚）は カードの効果は 全て出ない（2026-11-23 依頼者）

- 階段革命に ジョーカーも 使える（例：♥7・8・9＋ジョーカー）（2026-11-23 依頼者）

- ジョーカー上がり：ジョーカーだけ では だめ。ほかのカードと 組み合わせれば 上がってよい（例：♥3＋ジョーカー）（2026-11-23 依頼者）

- 5飛びで 一周して 自分に戻ったら（4人で 5を3枚 など）、場は 流れず 2周目として その人の番（2026-11-23 依頼者）
- ジョーカー1枚に スペードの3を出したら 場が流れて、スペ3を出した人から（スペ3返し。2026-11-23 依頼者）
- 上の 状態の札（逆回り・革命中・イレブンバック中・階段しばり・マークしばり）は 発生中なら 色つき（2026-11-23 依頼者）

## 仮で決めたこと（まだ確認していない）
1. ~~階段に ジョーカーは 使えない~~ → 使える（2026-11-23 依頼者）。9の代わりには なれない。上にも下にも のばせる時は、場に勝てる中で 強いほう
2. ジョーカーを ほかの数字の代わりにした時は、その数字の効果も出る（例：5＋JOKER＝5飛び2人）
3. ジョーカー1枚だけで出した時は 効果なし
4. しばり：前の人と全く同じマークの組み合わせで出すと しばり。ジョーカー入りの時は しばりにならない。しばり中ジョーカーは どのマークの代わりにもなれる
5. スペードの3がジョーカーに勝つのは、ジョーカー1枚に スペードの3を1枚 出した時だけ
6. ドロー3：墓地が3枚より少ない時は あるだけ見る。墓地が0枚なら何もなし
7. トレード4：先に出した人が相手の伏せた手札から1枚選び、次に相手が選ぶ。並びは毎回まぜる
8. ケメナイン：回収できる6が 自分の手札・場に あるときは なし
9. キングチャレンジ：墓地が0枚・手札が0枚なら なし（一番上が ジョーカーなら 当たり：2026-11-22 依頼者）
10. ケメゾディアの時、残りの順位は 先に上がった人 → 手札の少ない順
11. ゲーム中に通信が切れた人は CPU が代わりに打つ
12. 時間制限は なし

## 画面の分かりやすさ（2026-11-22）
- カードが動くアクション（ドロー3・トレード4・7渡し・エースカウンター・ケメナイン・10捨て・キングチャレンジで捨てる）は、カードが 飛んでいく動きと「〇〇 → △△ 何枚」の表示で見せる
- 中身が見えていい人（渡した人・もらった人）には 表、ほかの人には 裏で 飛ぶ
- もらったカードは 手札で 青く光り「NEW」が出る（6秒）
- キングチャレンジは めくったカードを 大きく見せる

- 縦向き専用（2026-11-22）。スマホを横にすると「縦にして」の案内が出る。ホーム画面に追加した時のアイコンは タイトルロゴ
- 選ぶ画面（キングチャレンジ など）は 画面が小さくても はみ出さず、スクロールできる

- ケメゾディアが出たら 依頼者の絵（design/kemezodia.png）が 画面いっぱいに 登場する（約3.5秒。タップで閉じる）

- リビングデッドのケメナインが出たら 依頼者の絵（design/kemenine.png）が 画面いっぱいに 登場する（約2.8秒。タップで閉じる）

- 墓地は 場のカードの 左横に 裏のカードの山で見せる（文字とは 別の段。文字に重ねない）。枚数ぶん 重なって 高くなり、下に「墓地 〇枚」
